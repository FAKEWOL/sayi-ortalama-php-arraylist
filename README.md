# Sayi-Ortalama

## Description
This repository contains a simple PHP script that calculates the average of an array of numbers.

## Features
- Calculates the sum of all numbers in the array.
- Divides the sum by the count of numbers to get the average.
- Outputs the average value.

## Installation
No installation is required. Simply run the PHP file on a server that supports PHP.

## Usage
1. Open the `Sayi-Ortalama.php` file in your web browser or via a command-line interface (CLI).
2. The script will display the average of the numbers in the array.
